# 零号实验区 · LAB ZERO

一个纯前端的 2D 俯视角战术枪战小游戏。启动时播放收容失效开场动画，随后进入简洁主菜单；包含**四名常规干员与一名隐藏传奇干员**、**敌意图鉴**、**无尽模式**、**三层折返式闯关模式**、**肉鸽无尽模式**、**训练场**、**视觉小说剧情模式**与**局域网 PVE / PVP 联机**：随机重组的实验层、迂回走廊、独立补给站、需要等待 3 秒的搜索、圆形视野、探索小地图、三名机制不同的区域 Boss、Boss 房区域封锁，以及最终通关结算。无需安装依赖、无需联网，所有地图、角色、特效、自适应战斗 BGM 与音效均由 Canvas / Web Audio 实时生成。

![闯关模式战斗](screenshots/campaign-gameplay.png)

> 当前版本：**BUILD 9.0.2**

## 开始游戏

**直接双击 `index.html`**，用 Chrome / Edge / Safari 打开即可。

如果浏览器对本地文件的音频或存档有限制，也可以在当前目录启动一个本地静态服务：

```bash
cd lab-zero
python3 -m http.server 8080
```

然后打开 <http://127.0.0.1:8080>。

建议使用桌面版浏览器 + 键鼠；游戏画面会自适应窗口大小，按顶栏的全屏按钮可进入全屏。

## 开场动画

页面首次加载会先播放约 10 秒的收容失效开场动画：

- 采用暗色实验室扫描线、事件报告和分段字幕，交代「深空生物研究所 · 第七区」与主角只剩一把手枪的背景。
- 可随时点击右下角「跳过 // SKIP」；按 `Enter` / `Space` / `Esc` 或动画结束后进入主菜单。
- 背景故事不再占用主界面；主菜单改为「模式 / 难度 / 部署 / 操作说明」的紧凑结构。
- 操作说明默认折叠，点击「操作说明」展开完整键位。
- 从游戏返回主菜单不会重复播放开场动画。

## 五个模式

### 无尽模式

原有的波次清剿玩法：每波实验体从四角进入，每 3 波遭遇士官长，清除一波后进入 15 秒休整。战斗等级、天赋点、26 节点五分支科技树、武器购买与改装、护盾 / 双持 / 炮塔 / 紧急重构、三种手雷和难度纪录全部保留。

### 闯关模式

从主菜单选择「闯关模式」进入。连续通过三张手工排布的折返式实验室地图，每张地图包含实验室房间、迂回连接的走廊、随机敌人、可搜索箱柜、一个独立补给站与终点前的区域 Boss。进入 Boss 房后区域会封锁，击败 Boss 才解除；随后终点电梯解锁，乘电梯进入下一张地图。通关第三张地图后进入最终结算。

### 肉鸽无尽

从主菜单选择「肉鸽无尽」进入。每次下潜都会随机生成一张实验室地图：7—9 个房间沿随机路径排布，房间尺寸、位置、主题、补给点和敌人分布都会变化，但保留折返走廊、圆形视野、3 秒搜索、独立补给站与探索小地图。

- 每层终点是「上行电梯」；普通层可直接下潜，每 **3 层**会出现一名随机区域守卫，必须击败守卫才能解锁电梯。
- 每层敌人数量和强度都会提高，且成长速度本身会加快：生命/伤害使用二次曲线递增，移速增长有上限，精英数量同步提高。
- 死亡后记录「肉鸽最深楼层」，从第 1 层重新开始；商店购买的武器、改装、属性与手雷在本局跨层保留。
- 肉鸽纪录按难度分别保存在 `labzero.rogueByDifficulty`（并保留 `labzero.rogueBestFloor` 作为历史兼容总纪录）；主菜单显示当前难度的最深楼层。

### 剧情模式：《零号：逃逸协议》

从主菜单选择「剧情模式」进入。主角阿兰（K-07）在收容失效中醒来，设施智能「零」通过耳麦引导他逃出 Astra Gene-Labs 第七区。

游玩流程采用视觉小说分镜、逐字对话和关键选择，参考明日方舟式的章节推进：

1. **序章 · 收容失效**：阿兰在隔离室醒来，选择是否信任零；玩家开始了解零号实验与收容失效。
2. **第一章 · 收容层**：第一场战斗，清除走廊内失控实验体；在观察室遇到被困的林澈博士，选择救她或继续前进。
3. **第二章 · 安保中枢**：第二场战斗，击败罗恩士官长与安保小队；罗恩临死前留下「你不是阿兰」的数据片，零号实验的真相开始翻转。
4. **第三章 · 动力核心**：第三场战斗，击败清道夫 X-7；面对零号的最终邀请，选择公开真相、独自逃离、引爆核心或接受零号。
5. **终章 · 零号协议**：根据救下林澈与最终选择进入不同结局。

四个结局：

| 结局 | 条件 | 内容 |
| --- | --- | --- |
| 黎明之前 | 救下林澈 + 公开真相 | 林澈与阿兰逃离，零号实验被曝光 |
| 无名者 | 独自逃离 | 阿兰活下来，但失去身份 |
| 余烬 | 引爆核心 | 设施与零号一同埋葬 |
| 新零号 | 接受零号 | 阿兰成为新的零号 |

剧情模式固定使用阿兰与普通难度，不开放商店和科技树；战斗使用预设装备，角色选择与难度会在退出后恢复。进入战斗前的对话结束后会自动切换至战斗 HUD，击败全部敌人后继续剧情。


主菜单的「设置」按钮和游戏内右上角齿轮共用同一个设置面板。从主菜单打开会返回主菜单，从战斗内打开会暂停行动并返回战斗；面板包含五个页签：

- **键位介绍**：按移动、战斗、交互、系统分组列出全部快捷键与模式限制。
- **玩法说明**：概览无尽、闯关、肉鸽、训练场、剧情五种模式，以及补给、Boss 封锁与紧急重构规则。
- **开发者**：输入密码 `qyxnb` 可启用全部武器（自动满级）、26 项科技树、全角色、无限弹药 / 无需换弹 / 无限视野 / 无限投掷物与生命锁定；可关闭能力增益。

设置面板可通过 `ESC ×`、底部按钮、`Esc` 键或点击遮罩关闭；底部按钮和 `Esc` 提示会根据入口显示「返回主菜单」或「返回战斗」。设置打开期间 BGM 会自动淡出。

## 单机性能优化

- **Retina 自适应分辨率**：持续监测实际帧耗时；高 DPI 屏幕平均帧时间超过 18.4ms 时逐级降低内部渲染分辨率（最低 0.75×），恢复余量后再缓慢回升。普通 DPI 屏幕保持原生分辨率。
- **HUD 限频**：战斗 HUD 从每帧刷新改为 **30Hz**，生命、装弹进度和技能冷却仍然即时可读，但显著减少 DOM 写入与布局。
- **小地图限频**：小地图改为 **20Hz** 重绘，不再占用每个渲染帧。
- **移除逐帧渐变 / 阴影**：敌人血条、玩家 / 敌方子弹、信用点、补给和攻击预警改为低开销纯色绘制；信用点不再逐枚启用 `shadowBlur`。
- **绘制裁剪与预算**：敌人、粒子、文字、子弹沿用视口裁剪；粒子和伤害文字继续按画质档位限制数量。
- **渲染循环容错**：单帧 Canvas / HUD 异常不会中断后续帧。

## 局域网联机（服务器权威）

局域网模式已从“房主浏览器模拟”彻底迁移为**服务器权威**（BUILD 9.0.2）。

### 架构

```text
浏览器客户端                Node 服务器
WASD / 鼠标 / 技能  ──────▶  server-authority.js
                            ├─ 玩家移动 / 武器 / 弹药 / 伤害
                            ├─ 敌人 AI / 波次 / Boss
                            ├─ PVE 救援 / 失败判定
                            └─ PVP 回合 / 排名 / 奖励
渲染 ◀──────── 30Hz 快照 ──┘
```

- 战斗模拟、AI、伤害与回合状态全部在 `server-authority.js` 中运行，服务器固定 30Hz tick。
- 客户端只负责输入、插值、预测和渲染，不再拥有权威状态。
- 房主仅负责大厅规则和开局，不再是游戏主机；房主离开不会中断战斗，服务器会转移房主标记。
- 客户端提交快照的旧接口已禁用，返回 `SERVER_AUTHORITATIVE`。

### 启动

```bash
cd lab-zero
node lan-server.js
```

本机 `http://localhost:8765/`，其他设备使用服务器地址。所有玩家打开同一服务器，输入相同房间码。

### 与单机统一

联机战斗直接复用单机资源：

- **同一张实验室地图与碰撞体**（`network-map.json` 从单机导出）
- **同一套 HUD / 画布渲染 / 小地图 / Boss 条 / 受伤反馈**
- **同一套角色模型、配色、生命 / 移速 / 减伤被动与主动技能**
- **同一套敌人模型与类型**：僵尸、疾尸、缠绕者、冲撞者、变异体、毒蜘蛛、士兵、精英、机器人，以及三名 Boss
- **同一套五把武器**、弹药、装填、散布和火箭范围伤害
- 敌人生命 / 伤害 / 数量随玩家人数提高
- 缠绕者虚化 / F 键挣脱、冲撞者眩晕、救援 / 倒地等机制均由服务器判定
- 服务器通过快照广播敌方子弹、玩家子弹、毒区、油桶、血包和战斗特效

当前联机使用独立战斗平衡：五把武器默认可用，单机的科技树、军械库购买、剧情与肉鸽进度不进入联机；单机模式完全不受影响。

### PVE

- 无尽波次、生物 / 军事 / 机械区域轮换，每 5 波区域 Boss。
- 团队总伤害、个人伤害、击杀、阵亡、救援统计。
- 全员倒地失败；倒地玩家可由队友按住 `E` 3 秒救援。
- 普通角色救援时不能移动，命脉可移动救援。

### PVP

- 1145 信用点 + 5 科技点开局。
- 回合制、按死亡顺序排名、按名次发放信用点与科技点。
- 9 处掩体、油桶、随机血包。
- `1—5` 切换武器；`Z / X / C` 购买伤害 / 护甲 / 射速强化。
- 服务器结算最终排名与战绩。

- 无限弹药：射击不扣除弹匣，HUD 显示 `∞`。
- 无需换弹：跳过装填流程。
- 无限视野：关闭闯关模式的战争迷雾，并揭示当前层小地图。
- 全部角色解锁（含隐藏传奇干员瓦尔基里），不需要消耗角色代币。
- 所有枪械自动满级：弹夹、枪管、瞄准镜、枪托全部为 MK IV。
- 投掷物无限：三种手雷均显示 `∞`，投掷不消耗库存。
- 生命锁定：血量保持不变，但受击伤害数字、红屏、画面抖动和音效仍正常触发；开发者模式下不会死亡。

开发者状态保存在 `labzero.developerMode`，刷新页面后继续生效；关闭「能力增益」后，无限资源停止生效，但已经解锁的武器、科技树与角色会保留。

### 三层地图

表中的敌人数量为「普通」难度基准，难度会继续缩放数量与数值。地图越深，敌人生命、伤害、移动速度和 Boss 生命都会提高；每层还有额外的地图推进奖励。

### 起点 / 终点电梯

- 每层开始处有一部起点电梯，靠近后按 `F` 确认。
- 每层终点有一部终点电梯。终点电梯在区域 Boss 被击败前锁定。
- 进入最终房间会触发 Boss 战；击败 Boss 后按 `F` 启动电梯。
- 第三层终点电梯启动后展示通关结算。

### 搜索箱柜（3 秒搜索）

房间与走廊中会随机放置补给箱、实验柜、储物柜、标本箱、数据机柜等可搜索对象。

- 靠近后按 `E` 开始搜索，**不会立即获得物资**。
- 搜索需要持续等待 **3 秒**，目标箱柜上方会显示环形进度与倒计时。
- 搜索期间可以移动和战斗，但离开箱柜约 90 像素后搜索会中断，进度清零。
- **搜索对象不参与碰撞，不会阻挡玩家、敌人或子弹。**
- 结果在 3 秒完成后结算：空箱、随机信用点、急救包、随机投掷物。
- 大致概率：30% 空、40% 信用点、16% 急救包、14% 投掷物。
- 信用点数量随地图深度提高，并受难度收益倍率影响。

### 有限视野与探索小地图

- 闯关模式使用以玩家为中心的圆形视野，无法看到整张地图。
- 右上角小地图只显示已经探索过的可行走区域；未探索区域保持黑色。
- 商店、未搜索补给点、起点 / 终点电梯和当前视野内的敌人会标记在小地图上。
- 敌人只在进入自身视野并拥有视线时才会发现玩家；此前不会主动寻路或攻击，只会原地警戒与扫视。

### 商店与成长

闯关模式没有每层结束的科技树、没有战斗等级成长，也不能靠杀敌获得天赋点。武器购买、武器改装和四项属性强化都只能在场景中的商店终端进行：

- 商店每层只有一个，并且有**独立的补给站房间**，不会与普通战斗房间混在一起。
- 补给站有专属地台、灯带、货架和大型全息终端；敌人与随机搜索点不会生成在补给站内。
- 靠近终端后按 `F` 开启，打开商店时行动暂停。
- 不在终端旁时按 `B` 会提示需要寻找终端。
- 初始状态：160 生命、300 CR、制式手枪、2 枚破片手雷、等级 1、无天赋。

#### 闯关属性强化

| 强化 | 每级效果 | 最大等级 | 初始价格 |
| --- | --- | ---: | ---: |
| 生命强化 | 生命上限 +20，并立即回复 20 生命 | 6 | 70 CR |
| 机动强化 | 移动速度 +4% | 5 | 80 CR |
| 装填强化 | 装填速度 +6% | 5 | 90 CR |
| 火力强化 | 所有武器伤害 +6% | 5 | 110 CR |

后续每级价格按 `基础价格 × (1 + 当前等级 × 0.8)` 递增，并取整到 5 CR。属性强化与已购武器都会跨地图保留。

武器、武器改装与手雷的规则与无尽模式相同，商店价格也一致。

### 三名区域 Boss

Boss 生命低于 50% 时进入**阶段 II**，移动速度和攻击 / 召唤频率提高。

进入 Boss 房间会立即触发**区域封锁**：房间入口出现脉冲能量屏障，玩家、Boss 与召唤物都被限制在房间内；房间外的普通敌人会被压制，不能进入或攻击。直到 Boss 被击败，屏障和移动限制才会解除，终点电梯同时解锁。

| 区域 | Boss | 生命基准 | 主要机制 |
| --- | --- | ---: | --- |
| 01 | 实验室主任 | 1250 | 冲锋枪连射；投掷毒瓶生成毒雾区域；召唤会追击并自爆的变异体 |
| 02 | 士官长 | 1700 | 霰弹枪扇形弹幕；火箭筒发射火箭；召唤安保士兵 |
| 03 | 清道夫 X-7 | 2400 | 蓄力冲撞；追踪火箭；加特林长连射；部署最多两座哨戒炮 |

Boss 生命另受难度与地图深度倍率影响。区域 Boss 被击败后会清除场上火箭与哨戒炮，并解锁终点电梯。

- Boss 血条精简为屏幕居中上方的窄条，只显示名称、阶段和血条，不再遮挡干员卡、小地图或中央演出文字。
- 每波结束的「区域已肃清」休整卡整体居中显示，避开了顶部干员卡、右上角小地图、右下角弹药卡和边缘按钮。

- 所有菜单、商店、科技树与暂停面板不再显示原生滚动条；内容仍可用滚轮浏览。

### 战斗音乐与受击反馈

- **自适应战斗 BGM**：进入战斗后由 Web Audio 实时合成鼓组、贝斯与琶音；普通战斗约 124 BPM，Boss 战自动切到更快的 150 BPM 并加入警报层，波次间休整切到低频 92 BPM 的平静段落。
- **主菜单 BGM**：主菜单使用约 82 BPM 的低频氛围段落，包含柔和脉冲、长音与高音铃；首次点击 / 按键后启动（浏览器自动播放策略），主菜单会显示「首次点击后开启主菜单 BGM」提示。
- 主菜单、设置、暂停、军械库 / 科技树终端、死亡与结算界面会按状态切换或淡出 BGM；页面切到后台时自动挂起音频，回到前台后恢复。
- BGM 与所有音效共用 `M` 键静音；不需要任何外部音频文件，首次点击开始后才会初始化 AudioContext。
- **受击反馈**：玩家受到实际伤害时会出现全屏红色闪屏与镜头震动，强度按伤害值以及该次伤害占最大生命的比例缩放；护盾吸收时只出现较轻的震动与红色脉冲。
- 重击会带来更长的红屏与更大幅度抖动，轻击则短促；红色闪屏位于 HUD 下方，因此不会影响血量、小地图和弹药的阅读。

### Boss 房间与刷新保护

- **肉鸽 Boss 房间**已调整到与对应闯关 Boss 房一致：生物层 450×350，安保层/动力层 400×400；房间、封锁线和上行电梯位置重新适配，不再使用偏小的普通房间尺寸。
- **闯关 Boss 刷新保护**：若出现关卡切换中断、旧存档异常或 Boss 实体被意外移出战场，而区域仍处于 Boss 封锁状态，系统会在 0.8 秒后重新生成该层指挥官；正常击杀后不会重复刷新。

### 宠物系统

角色菜单新增「角色 / 宠物」双页签，宠物与角色共用角色代币，购买与切换都在同一界面完成。当前提供三种宠物：

| 宠物 | 价格 | 效果 |
| --- | ---: | --- |
| 凉屋（蓝色小猫） | 40 代币 | 不会攻击；携带时角色代币获取 +20% |
| 浮游炮（悬浮机器人） | 60 代币 | 跟随发射激光；每 10 秒治疗玩家 20% 最大生命 |
| 旺财（黄色柴犬） | 40 代币 | 不会攻击；在场时信用点获取 +20% |

- 宠物在普通无尽、闯关、肉鸽与训练场都会跟随玩家。
- 宠物无敌、没有碰撞体积，不会被击杀或阻挡移动。
- 同一时间只能携带一只宠物，可随时在菜单中卸下。
- 浮游炮的治疗与激光均会自动触发，训练场中同样计入 DPS。

### 训练场

主菜单新增「训练场」模式：

无尽模式的 Boss 现在直接复用闯关模式 Boss 的完整技能状态机：

- **士官长**：霰弹枪扇形压制、追踪火箭齐射、召唤安保士兵。

Boss 的 HUD 名称、逼近提示、击破横幅仍按无尽区域绑定对应 Boss；技能、弹道、召唤物和场地技能与闯关模式一致。无尽模式中的 Boss 火箭、毒瓶、毒池与敌方哨戒炮均会正常更新和绘制。

### 无尽进度保存

从普通无尽中途主动退出时，会保存当前进度：

- 每波开始自动保存一次。
- 暂停菜单返回主界面、关闭页面时再次保存。
- 被击杀并进入死亡结算时会清除进度，不能续关。
- 主菜单开始按钮会变为「继续行动」，显示恢复波次，例如「从第 04 波恢复 · 普通」。
- 点击「继续行动」从保存波次重新开始该波，并继承角色、武器与改装、手雷库存、科技树/天赋点、等级/经验、信用点、击杀数、护盾、生命值、角色选择与难度。
- 若在休整期退出，则从下一波恢复。
- 进度按当前难度匹配显示；切换难度后旧进度不会误用，开启新局会清除旧进度。
- 菜单中的「放弃第 XX 波进度」可清除存档并新开一轮。

### 难度

开始行动前可在主菜单选择四档难度。难度影响敌人数量、生命、伤害、移速、Boss 生命、初始信用点与信用点收益：

| 难度 | 敌人数量 | 敌人生命 | 敌人伤害 | 敌人移速 | Boss 生命 | 初始信用点 | 信用点收益 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 简单 | 0.75× | 0.80× | 0.70× | 0.90× | 0.80× | 250 CR | 1.00× |
| 普通 | 1.00× | 1.00× | 1.00× | 1.00× | 1.00× | 200 CR | 1.00× |
| 困难 | 1.20× | 1.25× | 1.30× | 1.05× | 1.35× | 200 CR | 1.25× |
| 炼狱 | 1.00× | 2.00× | 3.00× | 2.00× | 2.00× | 200 CR | 2.50× |

炼狱模式额外拥有 **攻击速度 +50%** 与更强的攻击欲望：敌人索敌/攻击范围扩大，并会主动贴近目标；该难度独立记录最高波次、闯关与肉鸽成绩。

最高抵达波次按难度写入 `labzero.bestStats`，并保留旧键 `labzero.bestWave` 兼容；肉鸽最深楼层按难度写入 `labzero.rogueByDifficulty`，并保留 `labzero.rogueBestFloor` 作为总纪录。难度与模式选择都会保存到 `localStorage`，切换难度时纪录卡立即切换到该难度的数据。音效音量、BGM 音量与画质档位分别保存到 `labzero.sfxVolume`、`labzero.musicVolume` 与 `labzero.quality`；角色状态保存在 `labzero.characters`、`labzero.selectedCharacter`、`labzero.characterTokens` 与 `labzero.characterRewards`；开发者模式保存在 `labzero.developerMode`。

### 波次与 Boss

- 每波实验体会从实验室四角的隔离门进入。
- 普通士兵会接近并射击；精英士兵血量更高，会打出三连发。
- 每 **3 波**出现士官长。士官长会召唤普通士兵，并在血量低于 50% 时进入阶段 II。
- 清除当前波全部敌人后进入 15 秒休整；休整期间可以移动拾取金币或打开军械库 / 科技树。界面打开时倒计时暂停。

### 性能与资源优化

- 粒子、伤害文字、血迹、弹壳、传送门与投射物数量按画质档位动态限制；低画质下粒子预算约为高画质的 55%。
- 每帧不再反复创建过滤后的新数组，改用原地压缩，减少 GC 压力。
- 金币、拾取物、火焰区域、玩家/敌方投射物与传送门均设置硬上限，避免长时间战斗后内存无限增长。
- 页面切到后台时暂停 Canvas 渲染与模拟循环；回到前台后恢复并自动暂停。
- 炮塔数量上限 3，避免无限部署造成实体与索敌开销。

### 普通无尽倍速

## 实现说明

- **无尽地图**：2400 × 1500 的实验室场景在第一次加载时烘焙到离屏 Canvas。
- **闯关地图**：48 × 30 个 50px 网格，由房间 / 走廊矩形求并集；折返路线通过多段垂直 / 水平走廊拼接，不可行走的网格会合并成少量碰撞矩形，直接复用原有的圆形碰撞、子弹扫掠、视线遮挡和流场寻路系统。
- **肉鸽地图**：在 3 × 3 房间单元上用随机 DFS 选取 7—9 个相邻格，按路径顺序生成不同尺寸房间、中心点 L 形走廊、起点/终点电梯、一个补给站和可搜索点；每层重新生成并验证全部房间可连通。
- **肉鸽成长**：普通/精英数量按层数递增；普通敌人生命倍率约 `1 + 0.22d + 0.018d²`，伤害倍率约 `1 + 0.13d + 0.01d²`，移速有上限；每 3 层生成区域守卫，Boss 生命与伤害同样按二次曲线提升。
- **敌人体系**：每个体系各自有独立的 AI、移动逻辑和投射物；僵尸为近战追踪，变异体复用自爆状态机，毒蜘蛛使用带毒子弹，武装机器人使用机枪 / 霰弹 / 火箭三段状态机，维修机器人按冷却寻找受伤目标并治疗。标准无尽的 `endlessBiome` 每 5 波切换，闯关和肉鸽直接从关卡 / 楼层主题取敌人池。
- **角色**：玩家创建时读取当前角色，应用生命倍率、移速、体型、减伤、毒免疫与信用点倍率；主动技能由统一冷却与 HUD 状态机驱动，老爹毒区继承玩家的毒免疫判定；瓦尔基里拥有独立喷气背包移动、导弹库存/充能、全屏锁定与火箭筒三连发状态机。
- **碰撞**：演员使用圆形碰撞与子步进移动；玩家子弹、敌方子弹、Boss 火箭、炮塔子弹均使用带半径的扫掠碰撞。
- **敌人 AI**：闯关模式普通敌人初始为 `aware=false`，只在玩家进入其视野且视线未被墙体阻挡时转入追击 / 攻击；Boss 和召唤物则立即进入战斗。Boss 房封锁期间，房外敌人被冻结，房内角色被夹在房间范围内。
- **投掷物**：破片 / 闪光 / 燃烧三种手雷使用抛物线动画与延时引信；Boss 毒瓶使用独立抛物线并落地生成持续毒区。
- **Boss 火箭**：带有限转向速率的追踪火箭，撞墙或命中玩家半径后爆炸并计算距离衰减伤害。
- **搜索**：按 E 后进入 3 秒读条，进度绘制在目标上方；离开范围会中断，完成后才执行随机掉落结算。
- **Boss 区域封锁**：Boss 房入口按网格边界自动检测并绘制能量屏障；玩家、Boss、召唤物与哨戒炮的坐标会被限制在房间内，击败 Boss 后解除。
- **哨戒炮**：机器人 Boss 部署的敌方哨戒炮拥有独立射击冷却、视线检查和 12 秒寿命，Boss 被击败时清除。
- **音频**：战斗 BGM、Boss 层、休整层与所有音效完全使用 Web Audio 合成，不需要外部音频文件；第一次点击开始后初始化。音乐调度使用 16 分音符前瞻队列，切换模式时重新对齐段落并对增益做短淡入淡出。
- **受击反馈**：`hurtPlayer` 按实际扣血与最大生命比例计算反馈强度，驱动独立的全屏红色闪层和相机抖动；红层位于 HUD 下方，避免遮挡数值，闪层与低血量边缘脉冲互不覆盖。
- **设置与画质**：音效与 BGM 分别路由到独立增益节点；画质档位只改变 Canvas 的 DPR 上限与环境颗粒层，不改变碰撞、视野和战斗逻辑。设置面板本身不运行游戏模拟，因此打开即等于安全暂停。
- **存档**：无尽最高波次、难度、主菜单模式和闯关纪录均写入 `localStorage`；部分浏览器在 `file://` 下会禁用本地存储，不影响核心玩法。
